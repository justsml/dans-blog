# Talks

One directory per talk. Each holds its canonical `index.md`, the `adaptation-{15,30}min.md` route plans, the `script-{15,30,40}min.md` presenter scripts, its `bullets.md` rehearsal sheet (indexed in [bullets-index.md](bullets-index.md)), `packet.md`, `formats.md`, `CFP.md`, and hand-written evidence and fixtures. All of these are plain files now; the generators were removed on 7 September 2026.

Slide decks are not generated from outlines. They are hand-authored, one design per talk, in [artifacts/decks](../../decks/README.md), and the outline supplies only the speaker notes. The PowerPoint exports and per-route browser decks were removed on 7 September 2026.
