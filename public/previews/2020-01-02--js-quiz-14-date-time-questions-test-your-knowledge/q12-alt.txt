# 12. Date Setters Part 3

Which local calendar date does this object represent? Console display formatting may vary.

  const d = new Date(2020, 0, 1)
  d.setMonth(12)
  console.log(d)
------

1. Jan 01 2020
2. Jan 01 2021
3. Feb 01 2020
4. RangeError: Invalid argument.
